# Abbadi Tech Website — Specification & Quotation

## Major Specifications

| Area | Specification |
|---|---|
| **Type** | Custom lead-generation website for an independent Dubai DEWA approvals consultancy |
| **Positioning** | “Abbadi Tech is an independent consultancy and is not affiliated with DEWA.” |
| **Languages** | English + Arabic, full RTL support |
| **Pages** | Home, 12 services, 4 project types, 24 areas, FAQ, about, contact, legal pages |
| **Design** | Engineering-drawing-sheet style; Paper/Ink/Copper palette; Barlow Condensed + IBM Plex fonts; no AI/stock aesthetic |
| **Motion** | “Energise” hero + scroll story; reduced-motion fallback; no scroll hijacking |
| **CMS** | Payload CMS + Postgres/Neon; editable services, areas, FAQs, projects, legal |
| **Forms** | Quote/contact form, file upload, Turnstile spam protection, Resend email |
| **SEO** | Metadata, schema, sitemap, redirects, hreflang, canonicals |
| **Performance** | LCP < 2s, INP < 200ms, CLS < 0.05, JS < 170KB gzipped |
| **Security** | Sentry monitoring, R2 storage, consent, no exposed secrets |
| **QA** | Playwright, axe accessibility, Lighthouse, CI checks |
| **Content rule** | No invented claims, clients, reviews, fees or timelines; everything unverified stays unpublished |
