# Gate A documents

Read in this order:

1. `REFERENCE_TRACE.md` — what the reference site actually does, with evidence and limits.
2. `PRD.md` — product scope, audience, requirements and acceptance criteria.
3. `DESIGN.md` — the drawing-sheet design system and page templates.
4. `TECH_RULES.md` — stack, CMS, security, SEO, performance, accessibility, testing and deployment.
5. `SITEMAP.md` — URLs, priorities, redirects and hreflang.
6. `keyword-map.csv` — one primary intent per URL.
7. `content-briefs.md` — page-by-page content requirements.
8. `claims-to-verify.md` — the publication gate for factual and trust claims.
9. `todo.md` — Gate A/B/C work.
10. `GATE_A_SIGNOFF.md` — owner decisions and sign-off.

The coded design proofs are in `design/prototypes/`, with screenshots in `design/prototypes/screenshots/`.

Gate A stops after owner sign-off. Gate B production implementation starts only after that.
