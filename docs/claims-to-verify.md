## 8. Publication gate

Before any page is published:

1. Every claim on the page has a row in this register.
2. The row status is `verified`.
3. The evidence is stored in the CMS or the evidence folder.
4. The owner has approved the exact wording.
5. The page has a source list, reviewer and review date.
6. The independence notice is visible.
7. The page does not use the reference site's copy, images or entity name.
8. The Arabic version, if published, has been human-reviewed.

If any condition fails, the page stays in draft.
