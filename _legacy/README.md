# Legacy site — do not deploy

This folder contains the superseded static site that previously occupied the repository root. It is retained only so that owner-supplied photographs and redirect targets can be reviewed.

It is **not** part of the approved build. It contains unverified claims, a brand name that borrows the authority's name, a personal Gmail address in metadata, and an aesthetic that is excluded by the brief. Do not link to it, copy from it, or deploy it.

Recoverable assets require a rights and provenance check before use:

- Photographs: confirm the photographer, licence, model/property releases and whether each image shows Abbadi Tech work.
- Logos: the old logo is not approved for the new identity.
- Copy: every statement must be re-written and sourced.
- Contact details: the phone number, email and address must be confirmed by the owner.

The new site lives outside this folder. See `../docs/` and `../design/prototypes/`.
