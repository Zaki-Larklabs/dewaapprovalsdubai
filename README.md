## 🌐 How to Deploy to `dewaapprovals.abbaditech.ae`

### Option A: Deploy on Vercel (Recommended — 2 Minutes)
1. In your terminal, navigate to `c:\Abbadi\dewa-approvals-subdomain`:
   ```bash
   cd c:\Abbadi\dewa-approvals-subdomain
   npx vercel
   ```
2. In your Vercel Dashboard for this new project:
   - Go to **Settings** → **Domains**
   - Add domain: `dewaapprovals.abbaditech.ae`
3. Add the DNS record provided by Vercel in your domain registrar (e.g. GoDaddy, Namecheap, Cloudflare):
   - **Type:** `CNAME`
   - **Name:** `dewaapprovals`
   - **Target:** `cname.vercel-dns.com`

### Option B: Deploy to Netlify or Cloudflare Pages
- Drag and drop the `c:\Abbadi\dewa-approvals-subdomain` folder into Netlify / Cloudflare Pages.
- Assign the custom subdomain `dewaapprovals.abbaditech.ae`.

### Option C: Deploy on cPanel / Apache / Nginx Web Hosting
- Upload all files from `c:\Abbadi\dewa-approvals-subdomain` directly into the `public_html/dewaapprovals` directory of your server.
